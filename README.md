# Smile Weather / 验收记录

在线演示：https://smile-weather-ar-2027-oct21.wendy317.chatgpt.site

静态源代码：HTML + CSS + JavaScript，无构建步骤。解压源码后在该目录运行 `python -m http.server 8000`，用浏览器打开 `http://localhost:8000`。跨设备访问需 HTTPS。模型与 WASM 首次从 jsDelivr / Google 模型存储加载；不上传摄像头帧。

## 已验证

- JavaScript 通过 `node --check`。
- Sites 生产部署返回 succeeded，访问返回 HTTP 200；浏览器显示真实应用页面。
- 手动模式可以进入并运行渲染循环；它不能代替真人表情识别验收。
- PDF 已渲染检查，图集按20张独立图片编号。

## 待验证 / 限制

- 摄像头授权、模型完成加载、真人微笑与大笑分类准确率、真实头部反弹需在目标设备测试。
- 15Hz 推理限频是调度上限，并非任何设备都达到15Hz；CPU 推理在主线程可能阻塞，生产版应基于实测迁移至 Worker + transferable ImageBitmap。
- 头部为二维椭圆代理，缺少头发、耳朵遮挡和3D深度；快速粒子或头部运动有穿透风险。
- 固定池最多420粒子；满池丢弃新粒子。池搜索最坏420步，对固定上限有界，进一步规模化可用空闲栈。
- 页面转后台会停止摄像头，返回后须再次开启。
- Public 源码仓库：https://github.com/xuanwenmao46-coder/smile-weather-ar-2027

## 真人验收步骤

1. 授权摄像头，等待本地模型就绪；保持平静应无新特效。
2. 微笑超过140ms应开始下雨；收回笑容应停止生成新雨滴。
3. 保持微笑且张嘴，应出现烟花；连续保持最多每1.8秒一轮。
4. 显示边界，左右移动头部，检查镜像对应和星光弹出/反射。
5. 说话张嘴但不微笑，检查误触发；侧脸、遮挡、低光检验稳定性。
6. 脸离开超过250ms，清除碰撞体与触发状态。
7. 停止/后台切换，摄像头指示应关闭；拒绝权限、模型不可达应有失败提示。
8. 在iOS Safari、Android Chrome和PC Chrome测量渲染/推理P95及触发延迟。报告中预算为目标，不是测量结论。
